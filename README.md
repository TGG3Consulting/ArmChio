# ArmChio — бизнес-анализ переноса формата «Чио Чио» в Армению

Репозиторий содержит исследование российской сети японских экспресс-парикмахерских «Чио Чио», анализ рынка парикмахерских услуг Армении и финансовую модель адаптации формата под Ереван и регионы. Дата подготовки: 20.10.2026. Курс ЦБ Армении на 19.10.2026: 1 USD = 361,36 AMD; 1 RUB = 4,3731 AMD.

Финансовая модель прошла независимую верификацию (25 ключевых цифр открыты по первоисточникам, арифметика воспроизведена отдельным скриптом, базовые допущения оспорены) и пересчитана как **v2**; первая версия (v1) сохранена рядом для прослеживаемости правок. Что изменилось и почему — раздел 2.4 отчёта и раздел «Что изменилось в v2 и почему» в `model/financial_model.md`.

## Главный документ

- **`ArmChio_Business_Analysis.md`** — полный отчёт (резюме для инвестора, методология и верификация, разбор Чио Чио, рынок Армении, проект адаптации, финансовая модель v2, стратегические варианты, риски, дорожная карта с gate-KPI, источники).
- **`index.html`** — та же версия отчёта в HTML для чтения в браузере и публикации (оглавление с якорями, таблицы, светлая и тёмная темы). Открывается локально двойным щелчком, внешних скриптов нет.

## Как запустить модель

Требуется Python 3.10+ (для Excel — библиотека `openpyxl`).

```
pip install openpyxl
python -X utf8 -I model/model.py
```

Скрипт пересчитывает все сценарии и перезаписывает `ArmChio_model.xlsx`, три CSV и `model_output.json` в папке `model/`. Допущения задаются в начале `model.py`; каждое снабжено ссылкой на файл исследования, отчёт верификации или пометкой «оценка / допущение / решение». Скрипт проверяет тождества (выручка − расходы = EBITDA; EBITDA − амортизация = чистая прибыль; накопленный поток; состав документированных расходов; правило налога с оборота 10% − 6% документированных расходов, минимум 4,5%; gross-up ↔ net) и выводит результат проверки.

## Ключевые результаты v2 (базовый сценарий: 3 кресла, 30 м², спальный район Еревана, мастера-ИП с выплатой 50% выручки, загрузка 40%)

| Показатель | Значение |
|---|---|
| Средний чек | 2 345 AMD за услугу / 2 665 за визит (спальный район); 2 860 AMD (центр) |
| Выручка / чистая прибыль зрелой точки | 3,30 млн / 0,42 млн AMD в месяц (EBITDA 16,6%, чистая маржа 12,8%) |
| CAPEX на точку / потребность в финансировании с резервом | 8,98 млн AMD (≈$24,9 тыс.) / 11,86 млн AMD (≈$32,8 тыс.) |
| Безубыточность | 27 услуг ≈ 23 визита в день (загрузка 25%) |
| Окупаемость (пессим. / база / оптим.) | нет за 36 мес. / 31 мес. / 25 мес.; дисконтированной @18% у базы за 36 мес. нет |
| NPV 36 мес. @18% | −13,3 / −0,55 / +3,5 млн AMD; NPV 60 мес. базы +6,7 млн; IRR базы 15% |
| Франшиза Чио Чио («Лайт» / стандарт) | окупаемости нет за 36 мес., NPV −4,6 / −5,9 млн AMD |
| Ёмкость сети | Ереван 17–23 точки (база 18) + регионы 3–5; Армения 20–28 |
| Рекомендация | собственный бренд: пилот → gate ≥23 визитов/день к мес. 6 → 2 собственные точки → франшиза (1,0 млн AMD + 3%) только при доказанной загрузке ≥45%; холдинг из 3 собственных + 7 франчайзинговых точек за 36 мес. не окупается — горизонт 5+ лет |

Что изменилось относительно v1 (кратко): вычет 6% по налогу с оборота применяется только к расходам с расчётными документами (не к зарплате и аренде у физлица); базовая схема оплаты мастеров — ИП с документированной выплатой (на руки ≈85% брутто) вместо сотрудников; загрузка 40% вместо 45%; площадь 30 м² вместо 40; CAPEX дополнен шестью статьями и непредвиденным 15%; оборотный резерв вынесен из CAPEX; ёмкость сети 20–28 вместо 28–40; план 7 франшиз вместо 17; паушальный 1,0 млн вместо 1,5 млн. Итог: NPV базы из +2,7 млн стал −0,55 млн, окупаемость 25 → 31 мес.

## Дисклеймер

Документ подготовлен на основе открытых источников (сайты и каталоги франшиз, отзывы, реестры юрлиц, 2ГИС, объявления об аренде, Armstat, ЦБ РА, нормативные акты РА) по состоянию на 19–20.10.2026 и расчётной модели с явно помеченными допущениями. По сети «Чио Чио» независимых аудированных данных нет; заявления франчайзера и данные франчайзи приведены рядом и расходятся. Спрос на экспресс-формат в Армении не измерен и требует полевой проверки (раздел 9 отчёта). Цены аренды — цены предложения, не сделок; для спальных районов выборка составляет 3 объявления. Налоговая трактовка вычета 6% по выплатам мастерам-ИП и правовой статус схемы ИП-мастеров требуют письменных заключений бухгалтера и юриста до регистрации. Документ не является инвестиционной рекомендацией, юридической или налоговой консультацией.
