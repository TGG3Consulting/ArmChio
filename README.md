# ArmChio — бизнес-анализ переноса формата «Чио Чио» в Армению

Репозиторий содержит исследование российской сети японских экспресс-парикмахерских «Чио Чио», анализ рынка парикмахерских услуг Армении и финансовую модель адаптации формата под Ереван и регионы. Дата подготовки: 20.10.2026. Курс ЦБ Армении на 19.10.2026: 1 USD = 361,36 AMD; 1 RUB = 4,3731 AMD.

## Главный документ

- **`ArmChio_Business_Analysis.md`** — полный отчёт (резюме для инвестора, методология, разбор Чио Чио, рынок Армении, проект адаптации, финансовая модель, стратегические варианты, риски, дорожная карта, источники).
- **`index.html`** — та же версия отчёта в HTML для чтения в браузере и публикации (оглавление с якорями, таблицы, светлая и тёмная темы). Открывается локально двойным щелчком, внешних скриптов нет.

    ├── ArmChio_model.xlsx         # Excel: Assumptions / Prices / CAPEX / PnL_36m (формулы); Scenarios / Sensitivity / Network (значения)

## Как запустить модель

Требуется Python 3.10+ (для Excel — библиотека `openpyxl`).

```
pip install openpyxl
python -I model/model.py
```

Скрипт пересчитывает все сценарии и перезаписывает `ArmChio_model.xlsx`, три CSV и `model_output.json` в папке `model/`. Допущения задаются в начале `model.py`; каждое снабжено ссылкой на файл исследования или пометкой «оценка / допущение». Скрипт проверяет тождества (выручка − расходы = EBITDA; EBITDA − амортизация = чистая прибыль; правило налога с оборота 10% − 6% документированных расходов, минимум 4,5%) и выводит результат проверки.

## Ключевые результаты (базовый сценарий: 3 кресла, 40 м², спальный район Еревана)

| Показатель | Значение |
|---|---|
| Средний чек | 2 345 AMD (спальный район) / 2 860 AMD (центр) |
| Выручка / чистая прибыль зрелой точки | 3,71 млн / 0,53 млн AMD в месяц (маржа 14,4%) |
| CAPEX на точку | 9,09 млн AMD (≈$25,1 тыс.) |
| Безубыточность | 28 клиентов в день |
| Окупаемость (пессим. / база / оптим.) | нет за 36 мес. / 25 мес. / 16 мес. |
| NPV 36 мес. @18% | −12,0 / +2,7 / +14,2 млн AMD |
| Ёмкость сети | 23–33 точки в Ереване + 5 в регионах |
| Рекомендация | собственный локальный бренд (3 собственные точки, затем франшиза 1,5 млн AMD + 3%), а не франшиза Чио Чио |

## Дисклеймер

Документ подготовлен на основе открытых источников (сайты и каталоги франшиз, отзывы, реестры юрлиц, 2ГИС, объявления об аренде, Armstat, ЦБ РА, нормативные акты РА) по состоянию на 19–20.10.2026 и расчётной модели с явно помеченными допущениями. По сети «Чио Чио» независимых аудированных данных нет; заявления франчайзера и данные франчайзи приведены рядом и расходятся. Спрос на экспресс-формат в Армении не измерен и требует полевой проверки (раздел 9 отчёта). Цены аренды — цены предложения, не сделок. Документ не является инвестиционной рекомендацией, юридической или налоговой консультацией; перед принятием решений необходимо подтвердить налоговый режим, трудовое оформление и условия договора франшизы у профильных специалистов в Армении.
